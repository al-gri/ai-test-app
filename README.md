# AI Test App

A small web calculator generated by **DeepSeek Flash**, tested in isolated Docker
containers and independently reviewed through **Adaptive AI Team 1.1.1**.

Features: decimal arithmetic, parentheses, unary signs, keyboard input, clear
validation errors and a ten-entry in-memory history. Python standard library only;
no npm packages, external assets, tracking or API key is required to use the app.

```sh
python app/server.py --host 127.0.0.1 --port 8080
```

Open http://127.0.0.1:8080. The deployed Docker preview on the owner's PC uses
http://127.0.0.1:8088. This is a local demonstration, not an internet-facing service.

## Tests

Run the owner-controlled acceptance harness in a disposable container:

```sh
docker run --rm --network none --read-only --cap-drop ALL \
  --security-opt no-new-privileges --user 10001:10001 \
  --memory 256m --pids-limit 64 --tmpfs /tmp:size=64m \
  --mount type=bind,source="$PWD",target=/workspace,readonly \
  -w /workspace python:3.12-slim python tests/test_calculator.py
```

The deployed team uses stricter measured tmpfs snapshots and an independent
watchdog. Tests cover arithmetic/precedence, invalid inputs, HTTP behavior, body
limits, static assets and forbidden file paths. See [TEST_REPORT.md](TEST_REPORT.md).

## Portable team

`.ai-team/` contains the portable core, 102-role catalog and prompts. Only developer
and reviewer were activated for this small project. It contains no API key,
operational database, live lease or billing state. Installation into another
project starts with fresh project-specific approval and credentials.

The local integration and its limitations are documented in
[deployment/README.md](deployment/README.md). Core files remain at version 1.1.1;
the DeepSeek adapter is a project-specific deployment extension.

The run needed architect intervention after contradictory and truncated model
reviews. This successful test does **not** establish 95% unattended autonomy.
