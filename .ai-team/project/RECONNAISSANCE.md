# Project reconnaissance

New project: establish these facts before implementation.

- [ ] Read repository instructions; identify owner and authorized maintenance route.
- [ ] Record exact Git revision, local changes and project boundaries.
- [ ] Inventory product behavior, architecture, stack, dependencies and licenses.
- [ ] Inspect CI, tests and deployment without executing untrusted repository code.
- [ ] Map credentials/production boundaries; do not copy or publish secret values.
- [ ] Distinguish verified facts, hypotheses and unavailable evidence.
- [ ] Establish user goal, alternatives, market evidence and acceptance measures.
- [ ] Present a concise brief/options for owner approval bound to its exact digest.
- [ ] Set new budgets, role limits, sandbox/verifier/publisher access and stop rules.
- [ ] Validate useful imported lessons locally; do not inherit old project approvals.
- [ ] Authorize a bounded first change; preserve unrelated existing work.
